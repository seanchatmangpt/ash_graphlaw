# HANDWRITTEN

Ledger of every hand-written element that no pack capability emits. Each file carries the header
`# UNSUPPORTED(generator-capability): <reason>`. The machine copy is the `glx:UnsupportedResidue`
rows in `ontology.ttl` (gates/060); `scripts/ggen_sync.sh --check-ledger` requires every
`glx:residuePath` to appear in this file. Generated files are never hand-edited; see
`scripts/ggen_sync.sh --list-projections`.

## QRI beam-host projection (evaluated, not adopted)

`qri-qualification-profile-pack` `ggen-beam-host.toml` renders `abi`, `engine_load`, `host`, `pool`,
`wasm_config`, `vendor_task`, `verify_task` from `ontology/examples/ash-graphlaw-contract.ttl`.
Measured by rendering it in a scratch copy (output `generated/beam-host/*.ex`) and diffing against
`lib/ash_graphlaw/`: the output is a scratch-config projection (pack README: ggen reads only the
pack's own `ggen.toml`), not consumable through `[packs]` into `lib/` paths, and its moduledocs drop
the ABI, WASI, pin-resolution and pool-routing documentation of the hand-written modules. The
hand-written `host.ex`, `pool.ex`, `engine_load.ex`, `wasm_config.ex` and the vendor and verify
tasks therefore stay residue. `wasm_config.ex` additionally keeps the zero-ok limit gap.

## Generated files with a recorded residue

These paths are projections and stay generated; the residue is recorded, never hand-edited.

- `lib/mix/tasks/ash_graphlaw.install.ex`: the pack installer (ash-extension-pack, unchanged between
  marketplace `bd8e15d4` and `f897c7b4`) inserts the bare text `extensions: [AshGraphLaw.Resource]`
  with `Igniter.Code.Common.add_code/3`, which parses a statement, so `--target` raises
  `SyntaxError`. `scripts/ggen_sync.sh` therefore replaces the projection with
  `scripts/patches/ash_graphlaw.install.ex` (uses `Spark.Igniter.add_extension/5`, idempotent), but only
  while the pack output still carries the defect (grep guard; self-retiring). A local template cannot
  override it: ggen refuses two templates with one `to:` (FM-WRITE-008). The row is removed once the
  pack template emits `add_extension` correctly.
- `lib/ash_graphlaw/info.ex`: generated by the pack `info.ex.tmpl`; missing typespecs or docs
  beyond the template are residue. A superseded ledger path spelling, `lib/ash_graphlaw/resource/info.ex`,
  is kept here so an older ontology row still resolves.
