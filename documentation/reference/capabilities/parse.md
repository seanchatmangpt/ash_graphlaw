# parse

Parse text with the owning engine; counts quads or validates syntax.

- Wire operation: `parse` (registry order 3).
- Typed module: `AshGraphLaw.Capability.Parse`.
- Typed API: `AshGraphLaw.Capability.API.parse/2` and `parse!/2`.
- Result: `AshGraphLaw.Result.Parse`.

## Usage

```elixir
{:ok, result} = AshGraphLaw.Capability.API.parse([text: "..."])
```

`run/2` accepts the options of `AshGraphLaw.call/2` (server, timeouts, fuel). The request is
built and validated client-side without the engine; the call itself runs on the real engine.

## Request fields

| Field | Type | Required | Nullable | Default | Description |
|---|---|---|---|---|---|
| `text` | `string` | true | false | none | Text to parse. |
| `dialect` | `string` | false | true | none | Dialect name; sniffed when omitted. |
| `hint` | `string` | false | true | none | File extension or name hint for sniffing. |
| `base` | `string` | false | true | none | Base IRI. |

## Response

Untagged response.

| Field | Type | Required | Nullable | Description |
|---|---|---|---|---|
| `dialect` | `string` | true | false | Dialect used (Rust variant name). |
| `quads` | `integer` | false | false | Quad count; present for RDF dialects. |
| `id` | `string` | false | false | Content-addressed state id; present for RDF dialects. |
| `valid` | `boolean` | false | false | Syntax validity; present for non-RDF dialects. |

The decoded result also carries `:raw`, the entire response map, so no engine field is lost.

## Refusals

Refusal kinds: `Ambiguous`, `EngineRejected`, `NotSemanticContent`, `ResourceLimit`, `Unsupported`.

Refusal detail codes: `ResourceLimit`.

Client-side, a bad request refuses with `:invalid_capability_request` before the engine is called.
A refusal is an observation about one exact input and never grants authority.
