# sniff

Route text to a dialect and owning engine without parsing it.

- Wire operation: `sniff` (registry order 2).
- Typed module: `AshGraphLaw.Capability.Sniff`.
- Typed API: `AshGraphLaw.Capability.API.sniff/2` and `sniff!/2`.
- Result: `AshGraphLaw.Result.Sniff`.

## Usage

```elixir
{:ok, result} = AshGraphLaw.Capability.API.sniff([text: "..."])
```

`run/2` accepts the options of `AshGraphLaw.call/2` (server, timeouts, fuel). The request is
built and validated client-side without the engine; the call itself runs on the real engine.

## Request fields

| Field | Type | Required | Nullable | Default | Description |
|---|---|---|---|---|---|
| `text` | `string` | true | false | none | Text to route. |
| `hint` | `string` | false | true | none | File extension or name hint. |

## Response

Untagged response.

| Field | Type | Required | Nullable | Description |
|---|---|---|---|---|
| `dialect` | `string` | true | false | Sniffed dialect (Rust variant name). |
| `engine` | `string` | true | false | Owning engine (PurRdf or FrozenDuckdb). |

The decoded result also carries `:raw`, the entire response map, so no engine field is lost.

## Refusals

Refusal kinds: `Ambiguous`, `NotSemanticContent`, `ResourceLimit`, `Unsupported`.

Refusal detail codes: `ResourceLimit`.

Client-side, a bad request refuses with `:invalid_capability_request` before the engine is called.
A refusal is an observation about one exact input and never grants authority.
