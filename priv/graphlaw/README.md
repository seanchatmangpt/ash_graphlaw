# priv/graphlaw

This directory holds the GraphLaw WebAssembly engine that `AshGraphLaw.Host` loads.

## What is vendored

- `MANIFEST.json` (generated by ggen from `ontology.ttl`, never hand-edited): the pinned release,
  ABI version, artifact file name, download URL and SHA-256.
- `graphlaw.wasm` (fetched, git-ignored, not shipped in the hex package): the GraphLaw release
  asset for `v26.9.29`, ABI version 1.

The manifest pins the release asset, not a local build. GraphLaw derives and validates; it never
authorizes. The digest is an identity claim about bytes, nothing more.

## Refresh

    mix ash_graphlaw.vendor           # download the pinned URL, verify SHA-256, keep only on match
    mix ash_graphlaw.vendor --from P  # copy a local file, only if its SHA-256 matches the pin
    mix ash_graphlaw.vendor --check   # verify an existing file, write nothing, exit non-zero on drift
    mix ash_graphlaw.verify           # admit the file through EngineLoad and check the ABI version

A digest mismatch deletes the candidate and exits non-zero. To move the pin, change the literals
in `ontology.ttl` and regenerate; do not edit `MANIFEST.json`.

## Admissibility

Only a published release asset whose digest is recorded in `ontology.ttl` is admissible. A local
build of GraphLaw has a different digest, so `EngineLoad` refuses it with `:wasm_digest_mismatch`
and `--from` refuses to copy it.
